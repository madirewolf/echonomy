# ECHONOMY project rules

## Git and Netlify

- Never push to a remote unless Mohammad explicitly asks for a push.
- Batch related changes into one reviewed production push.
- Prefer local commits while work is in progress.
- Use Netlify Deploy Previews for visual checks before production.
- Do not trigger a production deploy for minor edits unless explicitly requested.
- Keep `.env`, access tokens, and Netlify environment values out of Git.
